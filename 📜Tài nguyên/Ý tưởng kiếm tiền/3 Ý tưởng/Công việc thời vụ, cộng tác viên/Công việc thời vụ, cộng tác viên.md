# Các công việc kiếm tiền nhanh
```dataview
LIST rows.file.link
FROM "📜Tài nguyên/Ý tưởng kiếm tiền/3 Ý tưởng/Công việc thời vụ, cộng tác viên"
GROUP BY split(file.folder, "/")[4]
WHERE file.name != this.file.name
```
